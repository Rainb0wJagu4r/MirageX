## 🛡️ Reporting a Vulnerability

We take the security of MirageX and the WRAITH container specification seriously. If you discover a vulnerability or security flaw, please report it responsibly.

### 📧 How to Report
- **Repository Issues / Security Advisories:** Open a private Security Advisory on GitHub at [github.com/Rainb0wJagu4r/MirageX/security/advisories](https://github.com/Rainb0wJagu4r/MirageX/security/advisories).
- **Direct Contact:** Reach out to the core maintainers via GitHub.

### ⏱️ Response SLA
- **Initial Acknowledgment:** Within **24 to 48 hours**.
- **Assessment & Triage:** Within **5 business days**.
- **Fix & Public Release:** Coordinated disclosure target within **30 to 90 days** depending on severity.
